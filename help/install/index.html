How to install the app

Gali Bazaar is not on Google Play yet, so you install it directly from our website. It takes about 2 minutes. One app for customers, shops, delivery partners and the sales team.

⬇ Download the app (Android)

1Download

  1. Open galibazaar.site on your Android phone in Chrome.
  2. Tap Download app (or the button above).
  3. If Chrome says “This type of file can harm your device”, tap Download anyway. The app is safe — it comes straight from Gali Bazaar.

2Install

  1. When the download finishes, tap Open (or open Files → Downloads → gali-bazaar.apk).
  2. The first time, Android asks to allow apps from this source. Tap Settings, turn on Allow from this source, then go back.
  3. Tap Install.
  4. If Google Play Protect shows a warning (“unknown app”), tap More details → Install anyway. It only appears because the app is not on Play Store yet.
  5. Tap Open. Done!

3Start using it

  1. Customers: tick the box and tap Continue with Google.
  2. Shop owners: tap Register your shop — see the Seller guide.
  3. Delivery partners: tap Join as delivery partner and enter your shop’s invite code — see the Delivery partner guide.
  4. Sales team: use Continue with Google with the email the admin added.
  5. Allow notifications when asked, so you hear new orders and updates.

4Updating the app

  1. When there is a new version, download it again from galibazaar.site and install it the same way.
  2. It installs over the old app — your login and data stay. Do not uninstall first.

5If something goes wrong

  • “App not installed” — free some space, or uninstall an old copy that came from somewhere else, then try again.
  • Can’t find the file — open Files (or My Files) → Downloads.
  • No “Allow from this source” option — Settings → Apps → Special app access → Install unknown apps → Chrome (or Files) → Allow.
  • iPhone — the app is Android only for now. Shops can use the seller panel on the website.
  • Still stuck? Write to support@galibazaar.site.

ऐप इंस्टॉल कैसे करें

गली Bazaar अभी Google Play पर नहीं है, इसलिए ऐप सीधे हमारी वेबसाइट से इंस्टॉल होता है। लगभग 2 मिनट लगते हैं। ग्राहक, दुकानदार, डिलीवरी पार्टनर और सेल्स टीम — सबके लिए एक ही ऐप।

⬇ ऐप डाउनलोड करें (Android)

1डाउनलोड

  1. अपने Android फ़ोन में Chrome से galibazaar.site खोलें।
  2. Download app दबाएँ (या ऊपर वाला बटन)।
  3. अगर Chrome लिखे “This type of file can harm your device”, तो Download anyway दबाएँ। ऐप सुरक्षित है — सीधे गली Bazaar से आता है।

2इंस्टॉल

  1. डाउनलोड पूरा होने पर Open दबाएँ (या Files → Downloads → gali-bazaar.apk खोलें)।
  2. पहली बार Android इस जगह से ऐप लेने की अनुमति माँगेगा। Settings दबाएँ, Allow from this source चालू करें और वापस आएँ।
  3. Install दबाएँ।
  4. अगर Google Play Protect चेतावनी दिखाए (“unknown app”), तो More details → Install anyway दबाएँ। यह सिर्फ़ इसलिए आता है क्योंकि ऐप अभी Play Store पर नहीं है।
  5. Open दबाएँ। हो गया!

3इस्तेमाल शुरू करें

  1. ग्राहक: बॉक्स पर टिक करें और Continue with Google दबाएँ।
  2. दुकानदार: Register your shop दबाएँ — सेलर गाइड देखें।
  3. डिलीवरी पार्टनर: Join as delivery partner दबाएँ और दुकान का इनवाइट कोड डालें — डिलीवरी पार्टनर गाइड देखें।
  4. सेल्स टीम: एडमिन ने जो ईमेल जोड़ा है, उससे Continue with Google करें।
  5. पूछने पर नोटिफ़िकेशन की अनुमति दें, ताकि नए ऑर्डर और अपडेट सुनाई दें।

4ऐप अपडेट करना

  1. नया वर्ज़न आने पर galibazaar.site से फिर डाउनलोड करें और इसी तरह इंस्टॉल करें।
  2. यह पुराने ऐप के ऊपर इंस्टॉल होता है — आपका लॉगिन और डेटा बना रहता है। पहले अनइंस्टॉल न करें।

5कोई दिक्कत आए तो

  • “App not installed” — फ़ोन में जगह खाली करें, या कहीं और से लिया पुराना ऐप हटाएँ, फिर दोबारा कोशिश करें।
  • फ़ाइल नहीं मिल रही — Files (या My Files) → Downloads खोलें।
  • “Allow from this source” नहीं दिख रहा — Settings → Apps → Special app access → Install unknown apps → Chrome (या Files) → Allow।
  • iPhone — अभी ऐप सिर्फ़ Android पर है। दुकानदार वेबसाइट पर सेलर पैनल इस्तेमाल कर सकते हैं।
  • फिर भी दिक्कत? support@galibazaar.site पर लिखें।
